# Yashel Kara — архитектурное портфолио

Веб-сайт-портфолио для презентации архитектурных проектов. Проект показывает практику создания многостраничного интерфейса, работы с JavaScript-модулями и организации контента проекта.

## 🔗 Демо

**GitHub Pages:** https://theruziev19.github.io/yashel-kara/

## 🛠 Технологии

- HTML5
- CSS3
- JavaScript (ES Modules)
- Responsive Web Design
- Git / GitHub Pages

## 📄 Структура сайта

- главная страница;
- каталог проектов;
- отдельная страница проекта;
- контакты;
- динамическое открытие проектов через параметры URL.

## ▶️ Запуск локально

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

После запуска откройте:

- `http://127.0.0.1:4173/index.html`
- `http://127.0.0.1:4173/projects.html`
- `http://127.0.0.1:4173/project.html?slug=raubichi-house`
- `http://127.0.0.1:4173/contact.html`

> Не используйте `file://`, поскольку проект использует JavaScript-модули.
